
# Foodie - Food Delivery Mobile App

## Project Description
Foodie is a modern food delivery mobile app interface created for VINIX Internship Task 6.

## Technologies
- HTML5
- CSS3
- JavaScript

## Features
- Mobile-friendly UI
- Food categories
- Food search
- Add to cart
- Cart total calculation
- Responsive design

## How to Run
1. Clone the repository.
2. Open the project in VS Code.
3. Open index.html using Live Server.
